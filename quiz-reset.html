I've used all my quiz attempts

Quiz attempts cannot be reset from the Help Centre, but Support can reset them for you.

If you have used all available attempts on a course quiz and have not achieved the required passing score, Baobab Support can reset your quiz attempts.

Before requesting a reset Make sure you know the name of the course you are taking. If you know the quiz name, include that too.

Ready to request a reset?

The form will ask for your course name, quiz name if applicable, and any additional details.
